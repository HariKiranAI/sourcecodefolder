# Online Appointment Booking System

A web-based application that allows users to book, manage, and track appointments online.

## 🚀 Features

### User Features
- **User Registration & Authentication** - Secure signup and login system
- **Appointment Booking** - Easy-to-use booking interface
- **Service Selection** - Choose from available services
- **Provider Selection** - Select preferred service providers
- **Time Slot Management** - View and select available time slots
- **Appointment Management** - View, reschedule, or cancel appointments
- **Email Notifications** - Confirmation and reminder emails
- **Profile Management** - Update personal information

### Admin Features
- **Dashboard** - Overview of appointments and system statistics
- **Provider Management** - Add, edit, and manage service providers
- **Service Management** - Create and manage available services
- **Appointment Management** - View and manage all appointments
- **Calendar View** - Visual calendar interface for appointments
- **User Management** - Manage user accounts and permissions

## 🛠️ Technology Stack

### Frontend
- **html** - User interface framework
- **CSS3** - Styling and responsive design

### Backend
- **js** - Runtime environment

### Database
- **MongoDB** - NoSQL database
